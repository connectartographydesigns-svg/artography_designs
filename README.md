# Artography Designs website starter

## Preview
Open `index.html` in a modern browser. The category pages are generated by `category.html?category=...`.

## Files
- `index.html`: homepage
- `category.html`: reusable portfolio category page
- `styles.css`: visual design, responsive layout and animations
- `script.js`: slider, keyboard controls and mobile navigation
- `category.js`: category content

## Before publishing
1. Replace all portfolio placeholders with real approved projects and media.
2. Replace the sample `mailto:hello@artographydesigns.com` with your real contact email or booking link.
3. Do not publish invented testimonials, client logos, ratings or claims. Add real reviews only after approval.
4. Test all links and mobile layout.

This is a static HTML/CSS/JavaScript site. GitHub Pages is free for eligible use, but check GitHub's current Pages terms for commercial/business suitability before choosing it as permanent hosting.
